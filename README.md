# Atlas Recall

Map recall game: countries, US states and their capitals, with a fun fact for each place.

Play it at https://dan66redford-maker.github.io/atlas-recall/

- Works offline once opened. On a phone, use "Add to Home Screen" to install it as an app.
- Progress is saved on your own device only.
- Map data: Natural Earth (public domain), via the world-atlas and us-atlas packages. Fonts: Bricolage Grotesque, IBM Plex Sans and IBM Plex Mono (SIL Open Font License).

To update: replace `index.html`, then bump `VERSION` in `sw.js` so installed copies pick up the change.
